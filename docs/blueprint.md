# **App Name**: STSPoint

## Core Features:

- Game Catalog Grid: A dynamic grid interface for selecting various game titles and top-up amounts with live pricing.
- ID Verification Tool: Automatic lookup system to verify user account IDs before payment to ensure credits are delivered to the correct player.
- Integrated Payment Hub: A streamlined checkout interface allowing users to select multiple payment methods like e-wallets and bank transfers.
- Order Transaction Ledger: Secure storage and display of previous transaction histories using a centralized database for user records.
- AI Support Guide Tool: An intelligent support tool that uses reasoning to troubleshoot common payment errors and guide users through verification steps based on real-time order data.

## Style Guidelines:

- Primary color: Vibrant Violet (#8E59FF) to evoke a futuristic gaming and tech-centric vibe.
- Background color: Midnight Slate (#141219), a deeply desaturated version of the primary violet to support high-contrast dark mode aesthetics.
- Accent color: Electric Cobalt (#2160FF), shifted 30 degrees for high-energy call-to-action buttons.
- Font pairing: 'Space Grotesk' (sans-serif) for high-impact techy headlines, paired with 'Inter' (sans-serif) for clean, readable body text and form inputs.
- Sleek, minimalist dual-tone icons that use neon gradients matching the violet and blue palette.
- Card-based dashboard layout with glassmorphic depth effects for a premium digital service feel.
- Smooth layout transitions using Framer Motion to animate product filtering and selection states.
